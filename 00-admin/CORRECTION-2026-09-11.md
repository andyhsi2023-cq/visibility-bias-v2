# Archive Corrections — 2026-09-11 (prepared for the R2 revision)

Dated notes correcting two items in the deposited working records. The original

## Correction 1 — attribution of the second passage-level coding

The work-log entry of 2026-06-19 names 李志辉 (Zhihui Li) as the second coder of
the 120-sentence passage-validation gold standard. **This naming was an internal
error.** The second passage-level coding was performed by **Liu Can** (刘灿), as
stated in the submitted contribution statement and in the Springer Nature change-
of-authorship form for JCSO-D-26-00240R1. The file `03-analysis/phase-K/li_labels.csv`
(whose "li" prefix abbreviates Liu) contains Liu Can's blinded labels; the intercoder
Cohen κ = 0.70 reported in §3.2.0 is computed from those labels. No other aspect of
the validation is affected.

## Correction 2 — unintended public release of confidential correspondence

Earlier public versions of the replication archive (Zenodo records 19569979,
20762481, 20762771, 20768140, 20768441; GitHub repository andyhsi2023-cq/
visibility-bias-v2) unintentionally included materials that should not have been
released publicly: the first-round referee report (`JCSO_review.pdf`), the R1
response letter quoting referee comments, the cover letter, cold-outreach
correspondence with third-party scholars (names and contact details), and the
internal working log. This was an oversight in archive preparation, not an
authorized release. These materials are removed from the revised archive (v6),
the GitHub repository has been rebuilt without them, and the journal editorial
office has been informed. Internal working notes (including the work log) remain
in the archive as transparent records of how the work was conducted; their candid
wording reflects internal quality-assurance discussion, not claims about the
manuscript.
